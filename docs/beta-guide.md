# 中文内测指南

## 安装

优先使用基础包。把 ZIP 解压到一个不会移动的固定目录，再从扩展管理页“加载已解压的扩展程序”。增强包只适合明确需要本地语义候选并愿意承担约 48 MB 解压体积的用户。

## 同步

1. 在小红书或抖音官方网页正常登录。
2. 进入个人收藏区域。
3. 点击浏览器工具栏里的“拾藏”。
4. 确认当前平台后点击同步，并保持该标签页打开。
5. 在同步中心查看“已发现 / 取得文字 / 已整理”和范围状态。

看到“范围未知”不是失败伪装：它表示当前页面没有经过验证的全量结束依据。此时数据会新增或更新，但不会自动移除旧记录。

## 更新

先导出备份。保持原扩展目录路径不变，把新版文件覆盖进去，然后到扩展管理页点击“重新加载”。不要用“卸载再安装”更新；卸载可能删除扩展 origin 下的数据。

## 备份与迁移

在“本地数据设置”点击“导出备份”。文件包含私人收藏，应放在受保护的本机位置。新设备安装扩展后，从同一页面选择 JSON 备份恢复。

## 删除

“删除全部本地数据”要求输入完整确认词，会删除真实库、演示库、摘录、向量和索引。卸载扩展不应替代产品内清理，因为不同浏览器对卸载数据的处理与恢复能力不可作为可靠工作流。

## 反馈格式

不要发送真实标题、正文、截图、DOM、HAR、Cookie 或账号 ID。请只提供：浏览器版本、平台、页面类型、适配器版本、匹配数量、范围状态、错误代码和是否可稳定复现。
