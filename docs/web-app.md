# 网页版使用与边界

公开网页版地址：<https://lccs02.github.io/cs-xhs-dy/>

## 打开即用

网页版不要求注册、登录拾藏账号或安装扩展。首次打开后可以：

- 单条保存小红书或抖音内容链接、标题、作者和用户主动提供的可见文字。
- 按 `链接 | 标题 | 正文（可选） | 具体对象（可选）` 批量粘贴导入。
- 在浏览器本地完成关键词分类、摘录、检索和同一对象并列查看。
- 导入、导出与扩展版兼容的 JSON 备份。
- 首次联网访问后，使用同源 Service Worker 缓存已经访问过的网页资源。

数据写入当前站点 origin 下的 IndexedDB。本站没有业务后端、账号系统、分析埋点、远程字体或云模型。

## 为什么网页不能自动读取平台收藏

普通网页受浏览器同源策略约束，不能读取另一个网站的登录态页面、Cookie 或私有数据。为了把安装门槛降到最低，网页版将手工和批量导入作为主路径；它不会让用户向第三方服务器提交平台密码、Cookie 或验证码，也不会用服务端代理冒充用户访问平台。

需要从平台当前已展示的收藏页面读取时，仍可选择仓库中的浏览器扩展。扩展的真实平台全历史覆盖状态仍以 [平台能力矩阵](feasibility.md) 为准，网页版不会把手工导入包装成自动全量同步。

## 本地数据注意事项

- 清除站点数据、使用无痕模式、无备份更换设备，可能导致本地收藏丢失。
- IndexedDB 不是加密保险箱，无法防护已经控制浏览器或操作系统的其他人。
- 换设备或清理浏览器前，在“本地数据”中导出备份；新设备打开网页后再恢复。
- 演示库与真实数据库分离，演示记录不会进入真实收藏计数或真实库备份。

## 部署

`npm run web:build` 会生成 `dist-web`。`.github/workflows/pages.yml` 在 `main` 分支更新后执行构建，并发布到 GitHub Pages。
